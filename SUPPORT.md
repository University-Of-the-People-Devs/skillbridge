# Support

Welcome to SkillBridge.

If you need help with contributing, understanding the project, or getting started, use the appropriate channel below.

## Before Asking for Help

Before asking a question:

1. Check the `README.md`.
2. Review `CONTRIBUTING.md`.
3. Review `docs/contributor-guide.md`.
4. Check existing GitHub Issues.
5. Check GitHub Discussions for related conversations.

This helps avoid duplicate questions and keeps information organized.

## Contribution Questions

For questions about contributing, such as:

- How to get started
- Choosing an issue
- Branching
- Pull requests
- Code reviews
- Contribution workflow

Review:

- `CONTRIBUTING.md`
- `docs/contributor-guide.md`

If your question is not answered there, start a GitHub Discussion.

## Feature Ideas

If you have an idea that could improve SkillBridge:

- Check existing Issues and Discussions first.
- Use the Feature Request issue template when appropriate.
- Use GitHub Discussions for ideas that need broader community discussion.

## Bugs

If you discover a reproducible bug, use the **Bug Report** issue template.

Please include enough information for another contributor to reproduce the problem.

Do not report security vulnerabilities through public issues.

See `SECURITY.md` for security reporting.

## Design and UX

For UI/UX questions, design proposals, or design discussions:

- Check existing UI/UX issues.
- Participate in relevant GitHub Discussions.
- Reference the project's design documentation when available.

## Technical Questions

Technical questions may involve:

- Frontend development
- Backend development
- Database architecture
- GitHub integration
- Testing
- DevOps
- Mobile development

Use GitHub Discussions when the question requires community input.

For questions directly related to an existing issue, keep the discussion within that issue when appropriate.

## Community Discussions

SkillBridge is a collaborative project.

Contributors are encouraged to use GitHub Discussions to:

- Introduce themselves
- Share ideas
- Ask questions
- Discuss architecture
- Discuss design
- Share learning resources
- Propose improvements
- Connect with other contributors

## Getting Started

If you are new to SkillBridge, start with:

1. `README.md`
2. `CONTRIBUTING.md`
3. `docs/contributor-guide.md`
4. `docs/vision.md`
5. `docs/product-requirements.md`

Then browse the available GitHub Issues.

Look for issues labeled:

- `good first issue`
- `help wanted`
- `beginner`

## Respect the Community

Please follow the project's `CODE_OF_CONDUCT.md`.

SkillBridge is a global collaboration project. Be respectful, constructive, and willing to learn from other contributors.

## Final Note

There is no expectation that contributors know everything.

Questions, learning, discussion, and collaboration are part of the SkillBridge experience.

**Learn. Connect. Collaborate. Build. Prove. Grow.**
