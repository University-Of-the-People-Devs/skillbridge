# Code of Conduct

## Our Commitment

SkillBridge is a global community contribution project.

We are committed to creating an open, welcoming, respectful, and inclusive environment where students, developers, designers, researchers, and other contributors can learn, collaborate, and build together.

Everyone who participates in SkillBridge is expected to help maintain a professional and constructive community.

## Expected Behavior

Contributors are expected to:

- Treat others with respect and professionalism.
- Welcome contributors of different skill levels and backgrounds.
- Give constructive and respectful feedback.
- Ask questions when something is unclear.
- Be open to different technical and design perspectives.
- Give appropriate credit to other contributors.
- Respect project decisions and review processes.
- Focus discussions on improving SkillBridge.
- Help create a positive learning environment.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Insults or deliberately disrespectful communication.
- Threats or intimidation.
- Trolling or deliberately disruptive behavior.
- Sharing private or sensitive information without permission.
- Plagiarism or claiming another contributor's work as your own.
- Deliberately submitting malicious or harmful code.
- Repeatedly ignoring project guidelines or maintainer decisions.
- Any other behavior that makes participation unsafe or unnecessarily hostile.

## Collaboration

SkillBridge is a contribution-driven project.

Disagreements about technical decisions, design choices, or implementation approaches are expected. Contributors should handle disagreements through respectful discussion, evidence, testing, and constructive review.

Technical disagreement is not personal disagreement.

## Pull Requests and Reviews

Code reviews should focus on:

- Correctness
- Security
- Maintainability
- Performance
- Accessibility
- User experience
- Project requirements

Reviewers should explain concerns clearly and respectfully.

Contributors should be open to making reasonable changes based on review feedback.

## Reporting Problems

If you experience or witness unacceptable behavior, report it privately to the SkillBridge maintainers.

For security vulnerabilities, do not create a public GitHub issue. Follow the instructions in `SECURITY.md`.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions may include:

- A private warning
- Requesting changes in behavior
- Removing inappropriate content
- Temporarily restricting participation
- Removing a contributor from the project in serious or repeated cases

The response will depend on the severity and circumstances of the incident.

## Scope

This Code of Conduct applies to:

- GitHub issues
- Pull requests
- GitHub discussions
- Project meetings
- Community communication related to SkillBridge
- Other official SkillBridge spaces

## Final Principle

SkillBridge is built by contributors, not by a single developer.

We want every contributor to feel that their ideas, effort, learning, and collaboration are valued.

**Learn. Connect. Collaborate. Build. Prove. Grow.**
